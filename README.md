# Color Palette Selector

Interactive web application for exploring color palettes, previewing them across chart types, and navigating a two-dimensional similarity map. The built-in Palette Studio also supports custom palettes, browser collections, and JSON exports.

## Features

- Browse and filter palettes by type, size, and name.
- Preview the selected palette across multiple chart types.
- Compare palettes in a perceptual similarity space.
- Simulate common forms of color vision deficiency.
- Create custom palettes and save collections in `localStorage`.
- Export custom palettes as JSON.

## Setup

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

## Run Locally

```bash
python3 -m http.server 8000
```

Open `http://localhost:8000`.

## Data Workflow

### 1. Extract the base palettes

The extraction script reads the local snapshot in `data/source/`, merges optional files from `data/extra/`, and writes the website datasets.

```bash
python scripts/extract_palettes.py
```

To refresh the remote source snapshot before extraction:

```bash
python scripts/extract_palettes.py --refresh-source
```

### 2. Add optional Lospec palettes

```bash
python scripts/fetch_lospec_palettes.py
python scripts/extract_palettes.py --dedupe-by name+signature
```

Additional JSON sources placed in `data/extra/` are loaded automatically. See `data/extra/README.md` for the accepted formats.

### 3. Rebuild the similarity coordinates

```bash
python scripts/build_palette_coords_fast.py
```

The script builds perceptual palette descriptors in OKLab, reduces them to two dimensions with UMAP when available, and falls back to PCA when necessary.
